# 预约状态与开单状态编码

## 预约流程状态（BookingStatus）

来源于 `appoption seg=psstatus` 字典。记录在 `ExpvstollHung.psstatus_hung` 字段及预约相关表中。

### 预约 & 确认阶段

| 编码 | 含义       | 说明                     |
|------|------------|--------------------------|
| 100  | 普通预约   | 客户已预约，未到店       |
| 110  | 临近预约   | 预约时间即将到           |
| 120  | 推迟预约   | 预约被延迟               |
| 130  | 确认预约   | 客户/前台确认到店预约    |

### 服务进行中

| 编码 | 含义       | 说明                     |
|------|------------|--------------------------|
| 200  | 到店       | 客户已到店               |
| 210  | 开房       | 开始使用房间             |
| 220  | 员工开始   | 技师/美容师开始服务      |
| 224  | 仪器开始   | 美容仪器开始使用         |
| 227  | 仪器结束   | 美容仪器使用结束         |
| 230  | 员工结束   | 技师/美容师服务结束      |
| 240  | 关房       | 房间使用结束             |
| 250  | 呼叫清洁   | 请求清洁房间             |
| 260  | 清洁开始   | 开始清洁                 |
| 270  | 清洁结束   | 清洁完成                 |

### 预约结束 / 取消

| 编码 | 含义       | 说明                     |
|------|------------|--------------------------|
| 310  | 离店       | 客户离开店铺             |
| 390  | 取消预约   | 预约被取消               |

## 开单流程状态（PSSTATUS）

定义在 `genesis_backend/common/constants.py` 的 `PSSTATUS` 元组中。记录在 `ExpvstollHung.psstatus_hung` 字段，表示挂单/开单在当前门店服务流程中的进度节点。

| 编码 | 含义       | 说明                               |
|------|------------|------------------------------------|
| 10   | 开单       | 刚新建的挂单/开单，尚未到店        |
| 20   | 客户到店   | 客户已到店，可以开始服务           |
| 30   | 配料完成   | 服务所需配料/产品已准备完成        |
| 40   | 服务完成   | 服务/操作已完成                    |
| 50   | 可以结账   | 服务完成，可进行结账               |
| 60   | 下次结账   | 本次不结账，下次再结（挂账继续）   |
| 70   | 已结账     | 已结账完成，流程结束               |

**相关常量**：`CAN_CHECKOUT_FLAG = '70'` — 当 `psstatus_hung='70'` 时表示该单已结账。

**注意**：
- `psstatus_hung` 表示**服务流程状态**，不是结账状态本身
- 判断是否已结账应以 `expvstoll/toll` 表为准，不单独依赖 `psstatus_hung`
- 查询未结账挂单使用 `psstatus_hung__in=['10','20','30','40','50','60']`

## 在代码中使用

- 后端 `cashier/views.py` 中将 `psstatus_hung='70'` 设为已结账
- `assistant/data_tools.py` 的 `list_unsettled_guests` 使用 `psstatus_hung__in=['10','20','30','40','50','60']` 筛选未结账
- 新开单默认 `psstatus_hung='10'`
