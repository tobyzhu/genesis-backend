# 手工开单问题清单

记录时间：2026-07-31
状态说明：P1 为优先修复项，P2 为后续优化项；完成后更新状态。

## P1（已修复）

1. V2 退款开单为空壳
   - 页面只有“正常开单 / 退款开单”切换按钮，模板中没有退款/作废面板。
   - `checkedOutOrders`、`voidPanelOpen`、`addRefundToCart`、`confirmVoid` 等状态和函数只在 script 中解构，从未被模板使用。
   - 文件：`genesis_pc/src/views/adviser/BillingPageV2.vue`、`genesis_pc/src/composables/useBillingEngine.ts`
   - 状态：已修复。退款模式新增“已结账退款 / 挂单作废”面板，接入日期筛选、明细勾选、加入退款/作废明细。

2. 开单明细行缺少删除和正/退切换
   - 购物车行只有属性、折扣、付款方式等编辑，没有单行删除按钮，也没有正/退切换按钮。
   - `removeFromCart`、`toggleRefund` 在引擎里已实现但未接到 UI。
   - 文件：`genesis_pc/src/views/adviser/BillingPageV2.vue`
   - 状态：已修复。明细行新增正/退切换与单行删除按钮。

3. 后端会把现金行并入缺口最大的储值卡分组
   - `group_items_by_card` 将无卡现金项追加到缺口最大的卡组，结账时现金部分会被这张卡扣掉，支付意图被改变。
   - 缺口计算还忽略了 `secdisc` / `srvmondisc`。
   - 文件：`genesis_backend/adviser/views.py`
   - 状态：已修复。现金行始终独立成组；保存前新增会员归属、付款卡归属、消费权限、计次余次校验。

4. 卡片定价未形成闭环
   - `applyCardPricing` 只在 `selectCard` 时执行一次，先选卡后加项目不会重新询价。
   - `cardAllowed` / `cardReason` 没有 UI 展示，也不阻止保存。
   - 后端 `save_hung_order` 不校验卡余额、卡归属和消费权限，不匹配项目可保存，结账时才暴露。
   - 文件：`genesis_pc/src/composables/useBillingEngine.ts`、`genesis_backend/adviser/views.py`
   - 状态：已修复。选卡后新增项目会重新询价；明细行展示卡限制原因；保存前拦截不可消费项；后端同步校验。
   - 定价口径：储值卡折扣规则（DISCOUNT）只填“折扣率”，不动单价，小计按 数量×单价×折扣率−金额折扣 计算；固定单价（PRICE）/逻辑卡阶梯价才直接改单价。`card_pricing` 接口新增 `discounttype` / `disc` 字段供前端区分。
